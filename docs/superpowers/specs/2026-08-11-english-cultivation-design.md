# 英语的修仙之路 — 设计文档

> 日期：2026-08-11 | 版本：v1.0

## 项目定位

一款面向家教一对一场景的英语学习 Web 应用，以中国修仙文化为世界观，将单词学习映射为"灵力修炼"，语法学习映射为"功法修炼"，通过水墨画风格的 UI 营造沉浸式修行体验。

## 用户画像

- **老师**：家教，面对面一对一授课，用自己的笔记本电脑操作
- **学生**：小学/初中/高中，多个学生，每人有独立修仙档案
- **使用方式**：老师坐在学生旁边，在电脑上操作，学生在老师引导下学习

## 一、世界观体系

| 英语学习 | 修仙概念 | 说明 |
|----------|----------|------|
| 单词 | 🫧 灵力 | 每背 10 个单词 = 升 1 级 |
| 语法模块 | 📜 功法 | 所有功法统一存放在「藏书阁」，不分学段。学完 1 个功法 → 渡劫测验 → 通过 = 升 1 级 |
| 语法测验 | ⚡ 渡劫 | 必须通过才能升级，失败需重修 |
| 大境界 | 🏔️ 境界 | 累计足够单词 + 功法 → 突破境界 |

### 境界列表

| 境界 | 称号前缀 | 等级范围 |
|------|----------|----------|
| 🔰 炼气期 | 外门弟子 / 内门弟子 / 亲传弟子 | Lv.1-10 |
| 🧱 筑基期 | 筑基真人 / 筑基上仙 / 筑基天尊 | Lv.11-20 |
| 💎 金丹期 | 金丹道长 / 金丹天师 / 金丹天尊 | Lv.21-30 |
| 👁️ 元婴期 | 元婴老祖 / 元婴圣者 / 元婴帝君 | Lv.31-40 |
| 🔥 化神期 | 化神圣者 / 化神天君 / 化神至尊 | Lv.41-50 |
| ⚡ 渡劫期 | 渡劫仙师 / 渡劫道君 / 渡劫仙尊 | Lv.51-60 |
| 🌟 大乘期 | 大乘道祖 / 混元道祖 / 太上仙帝 | Lv.61-70 |

称号规则：每 10 级（一个境界）内有 3 档称号，大约每 3-4 级称号进阶一次。

### 境界突破门槛

| 当前境界 | 所需单词 | 所需功法 |
|----------|----------|----------|
| 炼气期 → 筑基期 | 50 词 | 3 功法 |
| 筑基期 → 金丹期 | 120 词 | 5 功法 |
| 金丹期 → 元婴期 | 250 词 | 5 功法 |
| 元婴期 → 化神期 | 450 词 | 6 功法 |
| 化神期 → 渡劫期 | 700 词 | 7 功法 |
| 渡劫期 → 大乘期 | 1000 词 | 8 功法 |

## 二、页面结构

```
                     ┌──────────────────┐
                     │    学生选择页     │
                     │  (所有学生卡片)   │
                     └────────┬─────────┘
                              │ 点击学生
                              ▼
            ┌─────────────────────────────────┐
            │          个人修仙主页            │
            │  境界 · 等级 · 称号 · 经验条     │
            │  灵力值 · 功法列表 · 渡劫记录    │
            │  [ 灵力修炼 ]  [ 藏书阁 ]     │
            └─────┬──────────────────┬────────┘
                  │                  │
                  ▼                  ▼
         ┌────────────┐    ┌──────────────┐
         │  灵力修炼   │    │   藏书阁      │
         │ (背单词)   │    │ (全部功法)    │
         │ 选学段练词 │    │ 点击功法→详情 │
         └────────────┘    │ PPT + 渡劫    │
                           └──────────────┘
```

### 页面清单

1. **学生选择页** — 入口页，显示所有学生修仙卡片，新增时选择学段（小学/初中/高中），决定单词词库难度
2. **个人修仙主页** — 学生修行面板，展示等级、经验条、境界称号、灵力值、已学功法、渡劫记录
3. **灵力修炼页** — 单词学习区，按学生学段出词，背完一组 10 个升一级
4. **藏书阁** — 所有功法（语法模块）统一展示，不分学段，点击进入功法详情
5. **功法详情页** — 展示 PPT 内容 + 启动渡劫按钮
6. **渡劫页** — 语法测验，通过升一级，失败重修

## 三、UI 设计：水墨画风格

### 配色方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 页面背景 | 宣纸色 | `#f5f0e8` |
| 主文字 | 墨色 | `#2c2416` |
| 卡片/面板背景 | 淡墨 | `#e8e0d5` |
| 边框/分割线 | 淡墨线 | `#c8bfad` |
| 强调/按钮 | 朱砂红 | `#c8323c` |
| 境界/高亮 | 鎏金黄 | `#b8860b` |
| 次级文字 | 灰墨 | `#6b5e4e` |

### 设计元素

- **字体**：标题用楷书/行书风格（`font-serif`），正文用易读的无衬线体
- **卡片**：微妙的阴影 + 宣纸纹理感，边框用细墨线
- **装饰**：水墨笔触、山水云雾元素作为背景
- **按钮**：印章风格，朱砂红底白字
- **经验条**：水墨晕染的渐变效果
- **动画**：墨迹展开、烟雾飘散等淡雅过渡

## 五、数据模型

```typescript
interface Student {
  id: string;
  name: string;
  grade: 'primary' | 'middle' | 'high';  // 学段，只影响单词词库，功法统一在藏书阁
  level: number;           // 当前等级
  title: string;           // 当前称号
  spiritPower: number;     // 灵力值 = 累计背词数量
  spellsLearned: string[]; // 已学功法ID列表
  tribulationRecord: {     // 渡劫记录
    spellId: string;
    passed: boolean;
    date: string;
  }[];
}

interface Spell {  // 功法 = 语法模块，不分学段，统一放在藏书阁
  id: string;
  name: string;
  category: string;        // 状语/定语/时态...
  expReward: number;       // 通过渡劫后经验奖励
  pptUrl?: string;         // PPT 内容（后续添加）
  quiz: Question[];        // 渡劫题目
}

interface Question {  // 渡劫题目
  type: 'choice' | 'fill';
  stem: string;
  options?: string[];
  answer: string;
}

interface Realm {  // 境界
  name: string;            // 炼气期/筑基期...
  minLevel: number;
  maxLevel: number;
  wordRequirement: number;
  spellRequirement: number;
}
```

## 六、核心逻辑

### 升级判定

1. 背完 10 个单词 → 自动升 1 级，灵力值 +10
2. 学完功法 → 进入渡劫测验 → 全部答对通过 → 升 1 级
3. 渡劫失败 → 不升级，记录失败，可重新挑战

### 境界突破判定

- 每升一级后自动检查：当前灵力值 & 已学功法数 是否达到下一境界门槛
- 达标 → 自动突破，切换称号前缀
- 不达标 → 留在当前境界继续修炼

### 称号进阶

- 每 3-4 级自动切换称号（同一境界内逐步晋升）
